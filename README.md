# 📊 Gerenciador de Finanças Pessoais

Aplicativo Full-Stack seguro para controle de despesas e receitas, com cálculo de saldo em tempo real e autenticação de usuários.

## 🚀 Acesse o Projeto Online
- **Frontend (Interface):** [gerenciador-de-finan-n6ve9exjl-peter-8e9b.vercel.app]
- **Backend (API):** [https://gerenciador-de-finan-as.onrender.com]

## 🛠️ Tecnologias Utilizadas
- **Frontend:** React, Vite, React Router
- **Backend:** Node.js, Express, JWT (Segurança)
- **Banco de Dados:** PostgreSQL (Hospedado no Neon)
- **Deploy:** Vercel (Front) e Render (Back)
